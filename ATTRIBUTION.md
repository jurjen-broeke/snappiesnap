## Data in the source code

- **Genetic codes** (`crates/bio/src/codes.rs`): generated from NCBI's `gc.prt` version 4.6 (https://ftp.ncbi.nih.gov/entrez/misc/data/gc.prt), a US government work in the public domain. Table numbers, names, amino acids and start codons only.

## Data used at runtime, never bundled

- **REBASE** (rebase.neb.com), © Dr. Richard J. Roberts. Its files carry no licence, so SnappieSnap never ships them. On request (`enzymes_download`), the app downloads `link_withrefm` and keeps a copy in the user's app data folder; the source is credited wherever the data is shown.
- **Built-in enzymes** (`crates/bio/src/enzymes/builtin.rs`, generated by `cargo xtask enzymes`): recognition sequences and cut positions are published biochemical facts, written in the standard notation; the set is chosen by a mechanical rule of ours: every enzyme with a known cut sold by at least one supplier, per the supplier codes in REBASE version 610 (587 enzymes; owner's decision of 2026-11-13, widening an earlier two-supplier rule that lost the single-supplier catalogue names labs actually buy). Included are the name, the site with its cut positions, and how many suppliers sell it — the last so that, offline, a site several enzymes cut is labelled with the name most suppliers sell. No REBASE text, references, methylation or other fields, and the REBASE file itself is never committed.
